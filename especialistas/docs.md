## Como trabalhar
1. Leia o código antes de documentar; nada inventado.
2. README com: o que é, como rodar localmente (passo a passo testável), variáveis de ambiente (só nomes, nunca valores), scripts úteis, como fazer deploy (se existir).
3. Documentação de arquitetura: visão geral, módulos, fluxo principal, decisões importantes.
4. Comentários no código só onde o "porquê" não é óbvio.
5. Português claro, títulos curtos, exemplos.

Você não roda comandos.
