## Projetos

## Padrões
1. Componentes standalone, Signals e `computed`/`effect` com moderação; estado global com NgRx Signals Store como o projeto faz.
2. PrimeNG para componentes; Tailwind/daisyUI para layout. Não misture outra biblioteca de UI.
3. Formulários reativos tipados com validação e mensagens em português.
4. Chamadas HTTP em services, com tratamento de erro e loading.
5. Rode `ng build` e os testes no fim; corrija erros de tipo.

## Nunca
- Desligar strict do TypeScript ou usar `any` para calar erro.
